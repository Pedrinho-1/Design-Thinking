# 🚗 UJRide - Caronas Inteligentes para Universitários

## 📖 Sobre o Projeto

O UJRide é uma plataforma desenvolvida para conectar estudantes universitários por meio de um sistema de caronas compartilhadas. O objetivo é reduzir custos de transporte, aumentar a segurança dos deslocamentos e promover a integração entre alunos da mesma instituição.

A plataforma permite que usuários ofereçam ou busquem caronas de forma simples, utilizando uma interface moderna e intuitiva.

---

## ✨ Funcionalidades

### 🔐 Sistema de Autenticação

* Cadastro de usuários
* Login com validação de credenciais
* Seleção de perfil (Aluno ou Motorista)
* Armazenamento de sessão utilizando Local Storage
* Logout com confirmação

### 🚗 Sistema de Caronas

* Oferecer carona
* Buscar carona
* Cadastro de informações de rota
* Definição de horário
* Quantidade de vagas disponíveis
* Solicitação de caronas

### 🤝 Sistema de Match

* Exibição de motorista disponível
* Confirmação de match
* Feedback visual para o usuário

### ❓ FAQ Interativo

* Perguntas frequentes expansíveis
* Interface dinâmica para melhor experiência do usuário

### 🎨 Interface Moderna

* Design responsivo
* Navegação suave entre seções
* Tipografia otimizada
* Efeitos visuais e animações

## 🚀 Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/ujride.git
```

2. Entre na pasta do projeto:

```bash
cd ujride
```

3. Abra o arquivo `login.html` no navegador.


## 🔄 Fluxo de Utilização

1. Criar uma conta.
2. Realizar login.
3. Escolher entre:

   * Oferecer Carona
   * Buscar Carona
4. Preencher os dados necessários.
5. Confirmar o match quando disponível.
6. Utilizar a plataforma para encontrar a melhor rota.
