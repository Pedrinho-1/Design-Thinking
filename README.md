# GoCampus 

O GoCampus é uma plataforma web desenvolvida com HTML, CSS e JavaScript voltada para a conexão entre universitários através de caronas solidárias dentro do ambiente acadêmico. O projeto tem como principal objetivo facilitar a mobilidade dos estudantes, promover economia no transporte e incentivar práticas sustentáveis no campus.

O sistema possui uma interface moderna, responsiva e intuitiva, contendo:

- Tela de login interativa;
- Seleção de perfil entre Aluno e Motorista;
- Sistema de cadastro funcional;
- Visualização e ocultação de senha;
- Armazenamento local de usuários utilizando LocalStorage;
- Validação de campos de login e cadastro;
- Design responsivo para dispositivos móveis;
- Interface estilizada com foco em acessibilidade e experiência do usuário.

Além disso, o projeto foi desenvolvido com uma estrutura organizada e separação entre HTML, CSS e JavaScript, facilitando futuras manutenções, melhorias e integrações com banco de dados ou APIs.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

 *Objetivo do Projeto*

O projeto foi criado com foco acadêmico e social, buscando apresentar uma solução tecnológica para problemas de mobilidade universitária, incentivando a carona compartilhada, redução de custos e diminuição da emissão de poluentes.

Funcionalidades Futuras

- Integração com banco de dados;
- Sistema real de autenticação;
- Mapa interativo;
- Chat entre usuários;
- Sistema de avaliação de motoristas;
- Publicação e busca de caronas em tempo real.
